# Enterprise IT Administration Documentation

Welcome to my IT Administration documentation repository.

This repository contains Standard Operating Procedures (SOPs), installation guides, and troubleshooting documents based on my Windows Server, Active Directory, and Linux home lab projects.

The goal of this repository is to demonstrate practical IT administration skills and clear technical documentation similar to what is used in an enterprise IT environment.
